# MBT Connection: запуск SEO

1. Укажите подтверждённый адрес сайта в `SITE_URL`, например `https://<ваш-домен>`. Домен не найден в конфигурации проекта, поэтому до его настройки сайт отдаёт `noindex`, запрещает обход через `robots.txt`, а sitemap остаётся пустым.
2. Настройте редирект с альтернативного хоста (`www` или без него) на выбранный основной адрес в DNS/хостинге. Настройте HTTPS и редирект с HTTP на HTTPS на уровне хостинга. Без подтверждённого домена правило нельзя задать корректно.
3. После публикации проверьте `/robots.txt`, `/sitemap.xml`, canonical и Open Graph в исходном HTML. Запустите `npm run seo:check -- https://<ваш-домен>`.
4. Добавьте подтверждённые токены Google Search Console и Яндекс Вебмастера в `GOOGLE_SITE_VERIFICATION` и `YANDEX_SITE_VERIFICATION`. Затем отправьте `https://<ваш-домен>/sitemap.xml` в обе системы.
5. Профили Google Business Profile и Яндекс Бизнес подключайте только после подтверждения компании и адреса. Ссылки на неподтверждённые профили не публикуются.

Публичные страницы: `/`, `/services`, `/projects`, `/contacts`. Отдельные страницы по городам и узким услугам не созданы: доступного подтверждённого материала недостаточно для полезного уникального содержания. Городов филиалов, лицензий и методов прокладки в исходном сайте нет; эти сведения нужно подтвердить до публикации.

Подтверждённый пользователем адрес почты — `info@mbtconnect.kz`. В переданном SEO-задании указан другой адрес; при необходимости владелец должен подтвердить замену.
